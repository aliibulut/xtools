# XTools — X (Twitter) Browser Extensions

Powerful automation tools for X (Twitter) platform.

## Extensions

### 🔁 Retweet Liker
Automatically like retweets and tweets from selected accounts.
- Free: 50 likes/day
- Pro: Unlimited likes

### 👥 X Follow & Unfollow Pro
Auto follow and unfollow X accounts with advanced filters.
- Free: 25 follows/day  
- Pro: Unlimited follows
