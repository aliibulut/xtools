## Extensions

### ❤️ X AutoLike & Save Pro — `v1.56.0`

Automatically like and bookmark tweets from selected X accounts.

**Features:**
- Auto-like tweets & retweets from multiple accounts
- Auto-bookmark liked tweets simultaneously
- Skip RTs / exclude specific accounts
- Like interval control (seconds or minutes)
- Daily limit + loop mode
- Scheduler — auto-run at a specific time daily
- Live stats: liked / skipped / today total
- Multilingual UI: TR, EN, DE, FR, ES, IT, RU, JA, ZH, AR
