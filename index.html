// features

Built for Power Users

Every detail designed to give you full control with zero friction.

⏱️
Smart Scheduling

Set a specific time each day for automatic execution. The extension handles everything in the background.

🔁
Loop Mode

When a set completes, automatically start the next cycle. Define wait time between sets.

📊
Live Statistics

Real-time counters for liked, skipped, and today's total. Per-account tracking built in.

🎛️
Granular Controls

Fine-tune like intervals, time range filters (last 1 day, 6h…), daily limits and more.

🔒
Zero Data Collection

All settings stored locally in your browser. No data is ever sent to external servers.

🌍
11 Languages
